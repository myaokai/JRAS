# 不動産鑑定士試験 学習PWA ドキュメント

## 目的

不動産鑑定士試験の合格に向けて、スマートフォンで隙間時間に学習できるPWAを提供する。
オフライン動作・端末内での学習記録・間隔反復を軸に、「基準の暗記」と「過去問演習」を回せることを目指す。

## 試験科目とカバー範囲

| 試験 | 科目 | 現状 | 目標 |
|---|---|---|---|
| 短答式 | 鑑定評価理論 | ◎ 基準穴埋め・本文・過去問(R3〜R7) | 過去問解説と基準本文への紐付け |
| 短答式 | 行政法規 | △ 過去問(R3〜R7)のみ | 解説・法令別整理・数値暗記カード |
| 論文式 | 鑑定評価理論（論文） | ○ 基準暗記に利用可 | 暗唱チェック・論文過去問の論点整理 |
| 論文式 | 鑑定評価理論（演習） | × | 計算ドリル |
| 論文式 | 民法 / 経済学 / 会計学 | × | 一問一答・用語カード（優先度低） |
