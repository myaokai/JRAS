## 実装との差分（段階4-2時点）

- 05 セット結果：「前回との比較」は未実装（記録ダッシュボード 5-4 でまとめて扱う）。
- 06 短答 過去問の選択：「テーマ別」は法令タグ（FR-33、段階5）が前提のため未実装。「年度別」「間違えた問題」の2タブ。
- 03 出題範囲の選択：節が1つしかない章（総論第4章）は開閉せず、章の行だけで選ぶ。
- 12 演習 計算ドリル：手法は横にスクロールするチップで切り替える。計算過程は答え合わせ（または「わからない」）の後に1行目を出し、「次の手順」で1行ずつ・「すべて表示」で全部を出す。結果画面（05）は使わず、1問ずつ「次の問題」で続ける。

## Penpot MCP の利用方法

このレポで Penpot を操作するには、Claude Code に Penpot MCP サーバーを登録する。
トークンを含むため `.mcp.json` には入れず、local スコープ（`~/.claude.json` のこのプロジェクト用）に登録する。

```bash
claude mcp add --scope local --transport http penpot "https://design.penpot.app/mcp/stream?userToken=<トークン>"
```

利用時は、ブラウザで対象の Penpot ファイルを開き、MCP プラグインを接続したままタブを前面に保つ（バックグラウンドにすると、ブラウザがプラグインを一時停止する）。
