# 機能要件

- 要件ID: `FR` 機能要件 / `NFR` 非機能要件 / `DR` データ要件
- 優先度: **高** = 次に着手 / **中** = 論文式対応 / **低** = データ整備コストが大きい
- 状態: **実装済** / **一部** / **未着手**

---

## 1. 現行機能（実装済）

現時点の仕様を整理したもの。追加要件はこれを壊さないことを前提とする。

### FR-01 穴埋め問題モード

| 項目 | 内容 |
|---|---|
| 状態 | 実装済 |
| データ | `public/questions.json`（12章・137問。`{{答え}}` で穴埋め箇所を表現） |
| 出題 | 選択した章・節（FR-14）からランダムに 5／10／20問 |
| 操作 | 穴をタップで個別表示 / 「すべて表示」で一括表示 / 全表示後に「わかった」「わからなかった」で自己評価 |
| 出題方法 | すべて／要復習のみ（記録があり期限が来た問題）／未学習のみ（記録がない問題） |
| 結果 | 問題ごとの正誤と次回の復習日、今日の目標の達成状況、間違えた問題だけもう一度 |
| 実装 | `src/components/AnaumeQuestionView.tsx`, `src/components/QuizScreen.tsx`, `src/questionText.ts` |

### FR-02 過去問（短答式）モード

| 項目 | 内容 |
|---|---|
| 状態 | 実装済 |
| データ | `public/past_exams/`（令和3〜7年 × 鑑定評価理論・行政法規、各40問、計400問） |
| 出題 | ランダム10問（選択した試験の全問から）／本番形式（1つの試験の全40問を問題番号順） |
| 操作 | 選択肢を1つ選ぶと正誤と正解を表示 |
| 絞り込み | 「年度別」「間違えた問題」（FR-04 の期限到来分）をタブで切り替える |
| 履歴 | 1セットごとに日時・正答数・対象試験を記録し、開始画面に表示 |
| 実装 | `src/components/KakomonQuestionView.tsx`, `src/components/KakomonHistoryList.tsx`, `src/hooks/useKakomonHistory.ts` |

## 2. 追加要件: 短答式の強化（優先度：高）

### FR-11 過去問の解説表示

| 項目 | 内容 |
|---|---|
| 状態 | 実装済（表示の仕組み。解説データは 2-7 で順次作成） |
| 目的 | 正解だけでなく、各選択肢が正しい/誤っている理由を確認できるようにする |
| 仕様 | 解答後、問題全体の解説と選択肢ごとの解説（誤りの箇所・正しい記述）を表示する。解説がない問題は表示しない |
| データ | `KakomonQuestion` に `explanation?: string`、`KakomonChoice` に `explanation?: string` を追加（任意項目として後方互換を保つ） |
| 受入条件 | 解説がある問題で解答後に解説が表示される / 解説がない問題でも従来どおり動作する / `validate_questions.js` が新項目の型を検証する |

### FR-12 過去問 → 基準本文へのリンク

| 項目 | 内容 |
|---|---|
| 状態 | 実装済（穴埋めは問題の章・節へ自動でリンク。過去問は `kijunRef` を付けた問題から） |
| 目的 | 鑑定評価理論の過去問から根拠となる基準の箇所をすぐ確認できるようにする |
| 仕様 | 選択肢または問題に対応する基準の章・節を持たせ、解答後に「基準を読む」から教科書モードの該当節を開く。教科書から戻ると問題画面に復帰する |
| データ | `KakomonQuestion`・`KakomonChoice` に `kijunRef?: { chapter: string; section?: string }` を追加（節のない章は section を省く） |
| 受入条件 | リンクから該当節が表示される / 戻る操作でクイズの進行状態が失われない |

### FR-13 基準本文の音声読み上げ

| 項目 | 内容 |
|---|---|
| 状態 | 一部（`scripts/generate_audio.py` で章単位mp3を生成可能、アプリ未統合） |
| 目的 | 通勤・移動中に基準を聞き流して暗記する |
| 仕様 | 教科書の章画面に再生ボタンを置き、再生・一時停止・シーク・再生速度（1.0 / 1.25 / 1.5 / 2.0倍）を操作できる。バックグラウンド再生とロック画面操作（Media Session API）に対応する |
| オフライン | 音声はプリキャッシュ対象外とし、章単位で「オフライン保存」を選べるようにする（容量対策、NFR-03） |
| 受入条件 | iPhone Safari（ホーム画面追加）で画面ロック中も再生が続く / 保存済みの章は機内モードで再生できる |

### FR-14 穴埋めの節単位選択

| 項目 | 内容 |
|---|---|
| 状態 | 実装済 |
| 目的 | 苦手な節だけを集中的に回す |
| 仕様 | 出題範囲を章に加えて節単位でも選択可能にする（章選択で配下の節を一括選択） |
| 受入条件 | 節を1つだけ選んだ場合、その節の問題だけが出題される |

## 3. 追加要件: 論文式への拡張（優先度：中）

### FR-21 基準の暗唱チェック

| 項目 | 内容 |
|---|---|
| 状態 | 未着手 |
| 目的 | 論文式で求められる「基準を書き下す力」を鍛える |
| 仕様 | 定義・規定の見出し（例：「最有効使用の原則とは」）だけを表示 → 利用者が頭の中または紙で再現 → 「本文を表示」で全文と照合 → 自己評価（FR-04 に記録） |
| データ | `kijun.json` から暗唱単位（項目見出し + 本文）を抽出したデータセットを新設 |
| 受入条件 | 自己評価の結果が間隔反復に反映され、期限到来分だけを出題できる |

### FR-22 論文式過去問と論点整理

| 項目 | 内容 |
|---|---|
| 状態 | 未着手 |
| 仕様 | 年度別に論文式（鑑定理論）の問題文を表示し、論点リスト（答案の骨子）と関連する基準箇所へのリンクを段階的に開示する |
| 備考 | 模範答案の全文は著作権・作成コストの観点から持たず、論点の骨子に限定する |

### FR-23 演習（計算）ドリル

| 項目 | 内容 |
|---|---|
| 状態 | 未着手 |
| 対象 | 直接還元法、DCF法、原価法（再調達原価・減価修正）、取引事例比較法の補正、継続賃料（差額配分法・利回り法・スライド法） |
| 仕様 | 数値をランダム生成して出題し、数値入力で解答 → 正誤と計算過程を表示。許容誤差（端数処理）を問題ごとに定義する |
| 受入条件 | 同じ問題型でも毎回異なる数値で出題される / 計算過程が段階表示される |

## 5. 非機能要件

| ID | 項目 | 要件 | 状態 |
|---|---|---|---|
| NFR-01 | 対応端末 | iPhone Safari（ホーム画面追加）を主対象とし、Android Chrome・デスクトップでも動作する。縦向き前提 | 実装済 |
| NFR-02 | オフライン | テキストデータ（問題・基準本文・過去問）は初回アクセス後すべてオフラインで利用できる | 実装済 |
| NFR-03 | 容量 | プリキャッシュの合計を数MB程度に抑える。音声など大容量データは利用者が選んだものだけを保存する | 未着手 |
| NFR-04 | 学習データの保全 | 学習記録をJSONで書き出し・読み込みできる。あわせて D1 で複数の端末の記録を同期する（自分用、Cloudflare Access で保護）。機種変更やブラウザのデータ削除への対策。設計は [infrastructure.md](infrastructure.md) | 未着手 |
| NFR-05 | データ互換 | データ形式への項目追加は任意項目とし、既存の学習記録（問題IDキー）を失わない。問題IDは変更しない | 方針 |
| NFR-06 | 更新反映 | デプロイ後、次回起動時に新バージョンが反映される | 実装済 |
| NFR-07 | 品質 | データ変更時は `node scripts/validate_questions.js`、UI変更時は `verify_checks.cjs` で検証する | 実装済 |

## 6. データ要件

### DR-01 基準本文の欠落補完・抽出品質（対応済）

| 項目 | 内容 |
|---|---|
| 現状 | 第4章（節なし。章の前文に本文）と附則（id 13）は PR #15 で収録済み。ページの境目で文が切れる箇所と、見出しと本文がつながる箇所は段階1で修正した |
| 対応 | `scripts/extract_kijun.py` で、文末で終わらない段落はページをまたいでつなげ、マーカーで始まる短い行（Ⅰ 需要と供給の原則 など）を見出しとして独立させる。数式・表は `TEXT_FIXES` で個別に置き換える |
| 受入条件 | 教科書モードで第4章・附則の本文が表示される。`validate_questions.js` で章の本文の欠落を検出できる |
| 残り | 列記の最後の項目と後続の段落が1段落になる箇所（各論第3章第1節Ⅰ（３）など、ページ境界以外の原因）は未対応 |
