## 方針
- 問題データは持たず、手法ごとの生成関数で毎回数値を作る（`src/drill/`）。答えは表示単位で四捨五入し、問題ごとに許容誤差を決める。
- 7種類：直接還元法・DCF法・原価法・取引事例比較法・差額配分法・利回り法・スライド法。基準リンクは価格の手法が総論7章1節、賃料の手法が7章2節。
- 画面は `#/study/drill`（画面12）。状態は App が持ち、基準リンクで教科書へ行って戻っても残す。
- 解答は `mode: 'drill'`・`question_id: 'drill:<型>'` で記録する。今日の解答数・連続日数には数えるが、`buildProblemRecord` で除外して復習の対象にはしない。

- `npm test` 15ファイル・136件、`npm run build` 通過。`verify_checks.cjs` 70/70（ドリル14項目を追加）。
- 画面での確認（Playwright、390px）：表示された条件から計算した値で「正解」、誤った値で「不正解」、「次の問題」で同じ型の数値が変わる、手法の切替、「わからない」で答えと計算過程、「次の手順」で1行ずつ・「すべて表示」で全行、基準リンクで総論第7章第1節を開いて「問題に戻る」と同じ問題と結果が残る、ホームの今日の解答数に入り、復習期限には入らない。
- 取引事例比較法・DCF法の長い式も 390px で横スクロールが出ない（折り返して表示）。
- 許容誤差：直接還元法・原価法 ±1万円、DCF法 ±0.2%、取引事例比較法 ±0.5%、利回り法 ±0.1%（途中の利回り・現価率・比準単価を丸めて計算しても正解になる幅）、差額配分法・スライド法 ±100円。
- 簡略化している点：原価法は定額法・残価率0で、付帯費用や土地建物一体の減価は扱わない。取引事例比較法は単利の時点修正と格差率の掛け算。継続賃料は実質賃料（月額）で、差額配分は1/2法のみ。
- D1 の変更はない（`drill` は worker の検証で既に許可済み）。
