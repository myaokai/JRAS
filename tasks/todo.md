## レビュー

**PR A の結果**：`npm test` 65件、`npm run build`、`validate_questions.js`、`verify_checks.cjs` 46/46（段階2で17項目追加）がすべて通る。
- 節を1つ（総論第8章第4節）だけ選ぶと、その節の3問だけが出る。
- 結果画面の次回の復習日は、×が今日・○が翌日で、ライトナー方式の記録と一致する。「間違えた問題だけもう一度」で1問だけ出る。
- 本番形式は令和7年 鑑定評価理論を問1→問40の順に解け、履歴に40問のセットが残る。
- 解説（確認用に差し替えたデータ）が解答後に出て、基準リンクから教科書を開いて戻っても回答が残る。穴埋めでも同じ。
- 試験日と1日の目標は IndexedDB の settings に保存され、再読み込み後も残る（書き出しにも含まれる）。

**設計から変えた点・注意点**
- 「要復習のみ」は記録があり期限が来た問題、「未学習のみ」は記録がない問題とした（以前の「未習得・要復習」はこの2つを合わせたもの）。
- 過去問の「テーマ別」、結果画面の「前回との比較」は未実装（`wireframes.md` に差分を記載）。
- 解説データがまだないため、PR A の時点では画面に解説は出ない（PR B で追加）。
